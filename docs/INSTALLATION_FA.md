# راهنمای نصب نسخهٔ نامزد تحویل

این راهنما برای استقرار سامانه روی سرور داخلی کارفرماست. رابط و سرویس داده تحت وب هستند، اما فقط روی شبکهٔ محلی اجرا می‌شوند. مدل ترجمه نیز روی همان سرور یا یک میزبان داخلی در دسترس قرار می‌گیرد و برای ترجمه به اینترنت نیاز ندارد.

## اجزای تحویل

- بستهٔ برنامه با نام `translator-lab-1.0.0-rc.1.zip`
- تصویرهای آمادهٔ داکر با نام `translator-lab-docker-images-1.0.0-rc.1.tar`
- فایل کنترل صحت با پسوند `.sha256`
- دو مدل محلی `qwen/qwen3.5-9b` و `qwen3.5-4b`
- فایل پشتیبان تأییدشدهٔ کارفرما برای بازیابی اولیه

فایل‌های مدل به علت حجم زیاد جداگانه تحویل داده می‌شوند. مدل مترجم باید با نام دقیق `qwen/qwen3.5-9b` و مدل داور نخست با نام دقیق `qwen3.5-4b` در `LM Studio` بارگذاری شوند.

## پیش‌نیازها

- ویندوز سرور یا لینوکس دارای داکر و افزونهٔ اجرای ترکیبی داکر
- دست‌کم ۱۶ گیگابایت حافظهٔ اصلی برای برنامه و پایگاه داده، جدا از نیاز مدل
- کارت گرافیک مناسب برای اجرای مدل ۹ میلیاردی با کوانتیزه‌سازی چهار بیتی
- فضای آزاد کافی برای پایگاه داده، نسخه‌های پشتیبان و فایل‌های مدل
- دسترسی فقط از شبکهٔ داخلی به درگاه‌های رابط و سرویس

## نصب برنامه

بسته را در یک پوشهٔ ثابت باز کنید و فایل نمونهٔ تنظیمات را کپی کنید:

```powershell
Copy-Item .env.example .env
```

در فایل `.env` یک گذرواژهٔ قوی برای `POSTGRES_PASSWORD` قرار دهید. مقدار `DATABASE_URL` نیز باید همان گذرواژه را داشته باشد. کلیدهای سرویس‌های آنلاین در استقرار آفلاین خالی می‌مانند.

اجرای پیش‌فرض فقط از مرورگر همان سرور در دسترس است. اگر دسترسی از شبکهٔ داخلی لازم است، نشانی‌های مجاز را متناسب با نشانی ثابت سرور تنظیم کنید. این کار فقط پشت دیوارهٔ آتش یا درگاه معکوس دارای احراز هویت انجام شود:

```dotenv
WEB_BIND_HOST=0.0.0.0
FEATURE_API_ALLOWED_ORIGINS=http://192.168.1.20:3005
VITE_FEATURES_API_URL=http://192.168.1.20:3006/api/v1/features
```

در نمونهٔ بالا، `192.168.1.20` باید با نشانی واقعی سرور جایگزین شود. درگاه پایگاه داده همچنان فقط روی خود سرور باز می‌ماند.

در نصب اولیه، این سه مقدار باید به همین صورت باشند:

```dotenv
TRANSLATION_WORKER_ENABLED=true
TRANSLATION_AUTO_APPLY=false
TRANSLATION_ALLOW_API_APPLY=false
```

اگر سرور به اینترنت دسترسی ندارد، تصویرهای داکر را پیش از اجرا وارد کنید:

```powershell
docker load --input .\translator-lab-docker-images-1.0.0-rc.1.tar
```

سپس سرویس‌ها را اجرا کنید:

```powershell
docker compose up -d --no-build
```

در استقرار دارای دسترسی به مخزن بسته‌ها می‌توان تصویرها را روی سرور ساخت:

```powershell
docker compose up -d --build
```

## اتصال مدل محلی

در `LM Studio` سرور محلی را روی درگاه `1234` اجرا کنید و هر دو مدل را بارگذاری کنید. تنظیمات برنامه باید چنین باشد:

```dotenv
TRANSLATION_PROVIDER=local
LOCAL_TRANSLATION_BASE_URL_DOCKER=http://host.docker.internal:1234/api/v1
LOCAL_TRANSLATION_MODEL=qwen/qwen3.5-9b
PROPER_NAME_JUDGE_MODEL=qwen3.5-4b
PROPER_NAME_JUDGE_SECONDARY_MODEL=qwen/qwen3.5-9b
```

در صورت استفاده از `Ollama`، نشانی داکری روی رابط سازگار آن قرار می‌گیرد:

```dotenv
LOCAL_TRANSLATION_BASE_URL_DOCKER=http://host.docker.internal:11434/v1
```

## بازیابی دادهٔ اولیه

بازیابی فایل تأییدشده فقط زمانی انجام شود که جدول `public.geoms` هنوز وجود ندارد:

```powershell
$env:POSTGRES_PASSWORD = 'گذرواژه تنظیم‌شده'
pwsh -File scripts\restore_approved_database.ps1 -InputFile 'D:\path\backup_file_translated_final.sql'
```

## کنترل نصب

پس از آماده‌شدن سرویس‌ها، فرمان زیر سلامت، واژه‌نامه، مدل، قفل ثبت و ساختار پایگاه داده را کنترل می‌کند:

```powershell
pwsh -File scripts\verify_release.ps1
```

سپس آزمون‌های پذیرش طبق `docs/ACCEPTANCE_FA.md` اجرا می‌شوند. فقط پس از موفقیت آن‌ها می‌توان مقدار `TRANSLATION_AUTO_APPLY` را روی `true` گذاشت و بخش پشتیبان را دوباره ساخت یا راه‌اندازی کرد.

نشانی رابط مدیریتی در نصب پیش‌فرض چنین است:

```text
http://127.0.0.1:3005/
```
